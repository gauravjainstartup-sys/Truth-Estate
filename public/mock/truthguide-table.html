What has to change

Two edits. core.ts rule 3 currently reads “No markdown, no headings” — it needs an exception: when the reader asks for a table, emit a pipe table with a fixed column set. Then renderChat in chatLinks.tsx needs to turn consecutive pipe rows into a real table; today it renders bullets, numbers and bold, so a pipe table would print as raw text.

Columns, and the paywall

Project, Score, Corridor and From-price are already public — the whole scoreboard ships in /omni-index.json. Delay risk, ROI outlook and red flags are the forensic layer the ₹1,100 report sells, so they appear for a reader who has unlocked, and the free table stops at four columns. Why it scrolls

A seven-column table cannot fit a 390px phone. The table scrolls sideways inside its own bubble rather than widening the page, and the project name stays put as the readable anchor. Twelve rows shown, then the reply offers the next ten — the same “max 5, then offer more” instinct the prompt already has, relaxed for a table the reader explicitly asked for.
